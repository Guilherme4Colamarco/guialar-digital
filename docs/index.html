1

Você digita um endereço

Pode ser o site da escola, do banco ou um link que chegou por mensagem. Até aqui, o computador ainda não sabe onde esse site fica.

2

O computador consulta uma «lista de endereços»

Ela funciona como a agenda de contatos do celular: você diz o nome, ela devolve o número. Na internet, essa agenda se chama DNS. Toda vez que um site abre, essa consulta acontece primeiro.

3

O GuiaLar troca a agenda por uma que tem filtro

A agenda filtrada não informa o endereço de sites perigosos. Sem endereço, o site não abre. Os outros sites continuam abrindo como sempre.

Passo a passo

Três passos para proteger

Baixe e abra

É um arquivo só. No Windows, dê dois cliques no arquivo que termina em .exe. No Linux, é o arquivo .AppImage. Não tem instalador nem cadastro.

Escolha o modo e clique em «Proteger este computador»

Antes de mudar qualquer coisa, a janela mostra como o computador está agora e como vai ficar, e pede a sua confirmação. O sistema também pede a senha de administrador.

Confira ou desfaça quando quiser

O botão Verificar testa se o filtro está respondendo. O botão Desativar proteção devolve a configuração que o computador tinha antes.

Transparente e reversível

Feito para você confiar sem precisar entender de computador

Não espia ninguém

O programa não coleta o histórico de navegação e não envia nada para quem o desenvolveu.

Você vê o que muda

Nada acontece escondido. A janela mostra o antes e o depois e só diz «Protegido» quando o teste do filtro responde.

Volta atrás com um clique

O programa anota como o computador estava antes, só para poder devolver a mesma configuração quando você desativar.

Sem letra miúda

O que o GuiaLar não faz

Ele ajuda, mas não substitui a conversa em casa nem um antivírus. Estes são os limites:

  • Só protege este computador. Celulares, tablets e TVs da casa não entram. O programa existe para Linux e Windows.
  • Barra o site inteiro, não um pedaço dele. Um anúncio que mora dentro do próprio site que você visita continua aparecendo.
  • VPN e alguns aplicativos passam por fora. Um navegador ou aplicativo configurado para usar a própria «lista de endereços» (DoH) ignora o filtro.
  • O Windows pode mostrar um aviso. O arquivo .exe ainda não tem assinatura digital, então o SmartScreen pode dizer «editor desconhecido».
  • Desative antes de apagar o programa. Assim o computador volta à configuração que tinha.

Dúvidas comuns

Perguntas de quem não é da área

Preciso pagar ou criar uma conta?
Não. O programa é gratuito e não tem cadastro.
Meus filhos conseguem desligar o filtro?
Para ligar ou desligar, o sistema pede a senha de administrador do computador. Quem usa uma conta comum e não sabe essa senha não consegue desativar pelo programa.
Funciona no celular?
Não. O GuiaLar é um programa para computador com Linux ou Windows 10 e 11.
O Windows disse «editor desconhecido». É normal?
É. O arquivo ainda não tem assinatura digital, e o Windows avisa quando isso acontece. Baixe somente pelo botão desta página, que leva ao repositório oficial do projeto.
E se eu me arrepender?
Abra o programa e clique em Desativar proteção. O computador volta à configuração que tinha antes. No Windows, o bloqueador de anúncios que o programa colocou nos navegadores também sai.
O modo familiar também tira anúncios?
No Windows, sim: além do filtro, o programa coloca um bloqueador de anúncios no Chrome, no Edge, no Brave e no Firefox, que aparece quando o navegador é reaberto. No Linux, ele abre a página da extensão na loja de cada navegador para você instalar.
Quem faz a filtragem?
O GuiaLar não mantém lista própria. No modo familiar ele usa o serviço Cloudflare for Families; no modo só anúncios, o AdGuard DNS.

ModoO que bloqueiaDNS usado

Só bloquear anúnciosAnúncios e rastreadoresAdGuard DNS Padrão (94.140.14.14 / 94.140.15.15)

Pelo terminal:

guialar status            # estado e filtro ativo
guialar apply             # proteção familiar
guialar apply --mode ads  # só anúncios
guialar revert            # volta ao DNS de antes

No Linux: chmod +x guialar-*.AppImage e execute. Para ativar ou desativar, o sistema pede a senha de administrador (polkit ou sudo no Linux, UAC no Windows). Confira o download pelo arquivo SHA256SUMS da página de versões.

Registro. O único registro guardado (state.json) tem os endereços de DNS e os nomes das conexões, para poder desfazer. As decisões de projeto estão documentadas no repositório (pasta docs/adr).

Requisitos. Linux: NetworkManager, systemd-resolved ou runit/resolvconf; GTK 4 e Libadwaita para a janela (sem eles, funciona pelo terminal); glibc 2.34 ou mais nova. Windows: 10 ou 11, com PowerShell 5.1 ou mais novo.

Um Firefox instalado só para o seu usuário não recebe a política do bloqueador. Instale o uBlock Origin pela página do Firefox.

Vindo da versão beta? O AppImage antigo podia deixar uma pasta /tmp/appimage_extracted_*. Para apagar: sudo rm -rf /tmp/appimage_extracted_*.
