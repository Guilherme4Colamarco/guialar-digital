# GuiaLar Digital (Rust Edition)

Reescrita moderna, segura e de alto desempenho do GuiaLar Digital em Rust para Linux e Windows.
Configura automaticamente os servidores de DNS da Cloudflare for Families (1.1.1.3 / 1.0.0.3) e auxilia na instalação do uBlock Origin.

## Uso
- `guialar status`: Consulta o status atual da proteção.
- `guialar apply`: Ativa a proteção familiar.
- `guialar revert`: Restaura a configuração anterior.
- `guialar browser`: Abre a loja de extensões para instalar o uBlock Origin.
